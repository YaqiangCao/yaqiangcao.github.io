Introduction and Research Overview

I am a Research Fellow at the National Heart, Lung, and Blood Institute (NHLBI), NIH. My research in computational biology focuses on chromatin regulation in immunity, leukemia, and aging.

I develop computational and experimental methods for high-resolution enhancer–promoter and single-cell nucleosome mapping. My work examines how chromatin loops, histone modifications, and transcription factors shape T-cell differentiation, acute myeloid leukemia, and B-cell aging.

Through collaborations with biologists, physicians, and data scientists, I connect basic research with clinical applications and develop user-friendly software for epigenomic and 3D genome research.

Software Development

  • astroBoy (2022–Present): An automated, AI-assisted next-generation sequencing analysis platform for in-house and public datasets on a single-node server. Deployed at NHLBI/NIH; processed over 530 billion reads from more than 10,000 samples across 900 analysis jobs since December 2022.
  • glitter (2023–Present): An in-house web application for analyzing and visualizing single-cell RNA-seq data to support collaborative research.
  • VINCE (2023–Present): A Python package for nucleosome analysis using single-cell MNase-seq data, currently under active development and optimization. GitHub
  • cLoops3 (2026–Present): Chromatin interaction analysis software under development since 2026, with assistance from Codex for code enhancements.
  • Ryder (2026): A Python package for epigenomic normalization using internal reference regions and variable-feature detection. Accepted and published in Bioinformatics (2026). GitHub Paper
  • cLoops2 (2021): A Python package for comprehensive analysis of chromatin interaction data, including Hi-TrAC, HiChIP, and Hi-C (Nucleic Acids Research, 2022). GitHub
  • TOWN (2019): A Keras-based Python package for automated counting of live C. elegans in high-throughput bright-field microscopy images using deep learning. Developed for in-house drug screening to identify compounds that improve worm survival.
  • cLoops (2017): A Python package for accurate and flexible loop calling from 3D genomic data (Bioinformatics, 2020). GitHub
